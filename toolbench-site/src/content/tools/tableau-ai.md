## Overview

Tableau, owned by Salesforce, is the premier data visualization platform. Einstein AI adds natural language queries, automated data explanations, and predictive analytics. Best-in-class for visual analytics.

## Use Cases

Data analysts create dashboards, Salesforce orgs connect CRM data, and executives get AI-explained insights. r/tableau is an active community. Tableau Public is the largest free data viz repository.

## The Bottom Line

Best data visualization tool. $42/mo Explorer for analysts. Expensive but unmatched for visual analytics. Power BI is cheaper for Microsoft orgs; Tableau is better for visual storytelling.
